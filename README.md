# Asset Simulator

개인용 로컬 자산 시뮬레이터입니다. CAGR·Monte Carlo·현재가 기준 Power Law 성장 시나리오를 제공합니다. 세 모드는 위쪽 그래프 하나에서 전환합니다. React + TypeScript + Vite를 사용하며 백엔드는 없습니다.

## 실행

프로젝트 폴더의 **시뮬레이터 실행.cmd**를 더블클릭하세요. 서버를 시작하고 브라우저를 엽니다. 이미 실행 중이면 서버를 중복 실행하지 않습니다. 주소는 `http://127.0.0.1:5175/`입니다. 브라우저를 닫아도 서버는 유지되며 PC 재시작 시 종료됩니다.

Node.js 22.12 이상과 설치된 의존성이 필요합니다. 처음 설치하거나 터미널에서 실행할 때:

```powershell
npm.cmd install
npm.cmd run dev -- --port 5175 --strictPort
```

터미널 실행은 Ctrl+C로 종료합니다.

```powershell
npm.cmd run build
npm.cmd test
```

## 기본 화면 · CAGR

BTC·주식·현금·부채, 월 BTC/주식 투자금, 목표 연도와 연 수익률을 입력합니다. 초기 자산, 목표 연도의 예상 순자산, 물가를 반영한 순자산과 연도별 그래프를 표시합니다. 현재가·물가·부채 이율·시작 연도는 접힌 추가 설정에서, 상세 표는 결과 영역에서 펼칠 수 있습니다. 위쪽 그래프에서 CAGR·Monte Carlo·Power Law를 전환하며 그래프는 한 개만 표시합니다.

시작 연도에는 투자와 이자를 적용하지 않습니다. 이후 각 연도에:
- BTC 가격 = 초기 가격 × (1 + 연 수익률)^경과 연수
- BTC 수량 = 전년도 수량 + 월 투자금 × 12 / 해당 연도 가격
- 주식 = 전년도 주식 × (1 + 연 수익률) + 월 투자금 × 12
- 현금은 고정, 부채는 연이율로 복리 증가
- 명목 순자산 = BTC 평가액 + 주식 + 현금 − 부채
- 실질 순자산 = 명목 순자산 / 누적 물가배율

투자금은 외부 소득으로 연말에 추가하며 현금에서 차감하지 않습니다. 세금·수수료·상환·배당의 별도 현금흐름은 제외합니다. 기본값은 설명용 가정입니다.

## Monte Carlo

위쪽 그래프에서 Monte Carlo 탭을 선택한 뒤 ‘Monte Carlo 100,000회 실행’을 누릅니다. 실행·취소 버튼과 진행률·계산 오류는 이 탭에서만 표시합니다. BTC·주식 성장률과 물가상승률은 상단 포트폴리오 가정을 그대로 사용합니다. 자산·기간·투자금·부채 이율도 공유하며 변동성·환율·시장 움직임 설정만 별도로 관리합니다. 실행 후 같은 그래프에 결과 범위와 중앙값을 표시하고 명목/실질 기준을 전환할 수 있습니다.

- 항상 100,000회 실행 · 횟수 선택 없음
- BTC·QQQ 성장률과 물가는 상단 연동 · 변동성과 환율만 추가 설정
- 연도별 P10·P25·P50·P75·P90, 중앙값과 결과 범위 그래프
- 명목/실질 전환, 진행률, 취소, seed 재현, 실행 가정 기록
- 고급 설정: Normal / Student-t, 시장 국면별 상관계수·Markov 전이, BTC 급락·급등 이벤트

Normal은 로그정규 가격 모형입니다. 연간 성장배율 = `(1+평균수익률) × exp(-σ²/2+σZ)`이며 변동성은 로그수익률 표준편차입니다. Student-t는 분산을 1로 맞춘 단순수익률 충격을 사용하고 기본 손실을 −99.9%에서 제한합니다. 자유도는 2 초과 200 이하입니다. 두 모형의 변동성 정의와 실제 평균이 다를 수 있으며 상세 설명은 접힌 계산 방식에 있습니다.

시장 국면과 Jump는 기본 OFF입니다. 국면을 켜면 Normal 성장률은 상단 입력을 사용하고, Risk-On·Crisis는 기존 Normal 대비 성장배율 차이를 상단 성장률에 적용합니다. 예를 들어 BTC 기준이 10%에서 20%로 바뀌면 기존 Risk-On 25%는 (1.20 × 1.25 / 1.10 − 1) × 100%로 함께 이동합니다. 국면별 변동성과 충격 상관계수는 유지됩니다. Normal 성장률은 고급 설정에서 별도로 변경하지 않습니다. 첫 투자 연도에는 선택한 초기 국면을 사용하고 이후 Markov 행렬로 전이합니다. 각 전이 행 합계는 100%입니다. Jump는 연간 급락/급등/없음 중 하나를 추출해 BTC 성장배율에 곱하며, 사용자 BTC 수익률 제한은 마지막에 적용합니다.

물가배율은 경로마다 누적하고 실질 순자산은 각 경로의 물가로 나눠 집계합니다. USD/KRW는 매년 입력 평균 주변의 독립 로그정규 수준으로 추출하며 시작 환율은 입력 평균입니다. BTC·QQQ에는 같은 환율을 적용하고 현금·부채·투자금은 KRW입니다. 주식 자산 전체를 QQQ로 취급합니다.

결과 범위는 각 연도의 표본 분포이며 하나의 경로나 보장 범위가 아닙니다. 평균은 상세 표의 참고값입니다. 연도 수 × 경로 수는 메모리 보호를 위해 5,000,000 이하로 제한하며 계산 범위를 벗어나는 가정은 실행 오류로 알립니다.

## Power Law · 현재가 기준 성장

입력한 현재 BTC 가격을 시작 가격으로 고정하고 β만 조정합니다(기본 5.845). 가격 공식은 다음과 같습니다.

`P(t) = P0 × (t / t0)^β`

P0는 입력한 현재 BTC 원화 가격, t0는 시작 연도의 BTC 경과일수, t는 미래 연도의 BTC 경과일수입니다. 이는 일반적인 파워로우 `P = A × t^β`에서 `A = P0 / t0^β`로 기준점을 맞춘 형태입니다. β가 변경될 때 A도 다시 맞추므로 시작 가격과 시작 순자산은 변하지 않으며 미래 성장 곡선만 달라집니다. β=0은 가격이 일정합니다. 기본 β는 사용자가 조정하는 성장 가정이며 통계적으로 검증된 예측값을 뜻하지 않습니다.

경과일수는 BTC Genesis(2009-01-03)부터 각 연도 1월 1일 UTC까지입니다. 연도별 자산 스냅샷 간격을 일관되게 적용하며 시작 연도 범위는 2010~2200년입니다. 연도만 입력하는 앱이므로 시작 가격을 시작 연도 스냅샷의 가격으로 간주합니다. 실제 현재 날짜를 기준으로 한 일별 예측은 아닙니다.

매수 수량과 자산 평가에 같은 Power Law 가격을 사용합니다. 시작 연도에는 투자하지 않고, 이후 연간 투자금(월 투자금 × 12)을 다음 연도 스냅샷 가격으로 매수합니다. BTC CAGR 수익률과 Monte Carlo 환율 가정은 이 모드에 적용하지 않습니다. 주식·현금·부채·물가 가정과 외부 소득으로 투자한다는 가정은 공통으로 유지합니다.

그래프는 하나의 Power Law 성장 경로를 표시하며 상단 미래 요약과 같은 결과입니다. Bitbo API 근사 계수와 하한·기준·저항선은 제거했습니다. 명목/실질 기준 전환, BTC 가격·수량 툴팁과 연도별 상세 표를 제공합니다. 부채가 자산보다 크면 순자산은 음수로 표시됩니다.

## 그래프와 저장

연도 구간에 마우스를 올리면 값을 표시하고 클릭·터치하면 고정합니다. ‘선택 해제’ 또는 Esc로 해제하며 Tab·Enter·Space로도 조작할 수 있습니다.

설정은 같은 브라우저·같은 로컬 주소의 localStorage에 저장합니다. 저장 형식은 version 10이며 Power Law 베타도 저장합니다. 기존 Monte Carlo의 별도 성장률·물가 평균·실행 횟수는 읽지 않고 상단 입력과 100,000회 고정값을 적용합니다. 이전 설정의 자산·수익률·자동 조회 선택·Monte Carlo 가정은 보존하며, 삭제된 모델 설정은 복원하거나 다시 저장하지 않습니다. 이전에 다른 가격 경로를 선택했더라도 이제 기본 계산은 입력된 CAGR 수익률을 사용합니다. Monte Carlo 결과는 저장하지 않아 새로고침 후 다시 실행해야 합니다. 입력이 변경되면 이전 결과임을 표시하고 100,000회 재실행으로 갱신합니다.

## BTC 현재가

자동 조회를 켜면 접속 시 업비트 공개 API의 KRW-BTC 최근 체결 가격을 반영합니다. 직접 입력하면 자동 조회가 꺼지고, 조회 버튼으로 갱신할 수 있습니다. 연결 실패나 10초 시간 초과 시 기존 가격을 유지합니다. API 키는 필요 없으며 시세 조회에는 인터넷 연결이 필요합니다.
