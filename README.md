## 계산 방식

시작 연도는 현재 자산의 기준 시점이며 투자나 이자는 적용하지 않습니다. 이후 각 행은 1년이 경과한 시점입니다. 모든 금액은 KRW입니다.

- BTC 가격 = 초기 가격 × (1 + 연 수익률)^경과 연수
- BTC 수량 = 전년도 수량 + 월 BTC 투자금 × 12 ÷ 해당 연도 BTC 가격
- 주식 = 전년도 주식 × (1 + 연 수익률) + 월 주식 투자금 × 12
- 현금은 고정, 부채 = 전년도 부채 × (1 + 부채 연이율)
- 명목 순자산 = BTC 평가액 + 주식 + 현금 − 부채
- 실질 순자산 = 명목 순자산 ÷ (1 + 물가상승률)^경과 연수

추가 투자금은 외부 소득에서 조달하며 현금을 차감하지 않습니다. 투자는 연말에 일괄 반영합니다. 세금, 수수료, 상환, 월별 가격 변동은 제외합니다. 기본값은 시장 데이터가 아닌 예시이며 `src/simulation.ts`에서 관리합니다.

## BTC TAM 모델 — 시간에 따른 채택으로 개선

BTC 가격 모델에서 `Fixed CAGR`과 `TAM Model`을 선택할 수 있습니다. TAM은 Financial Gold, Bonds, Equities, Real Estate, Cash / Deposits를 각각 계산합니다. 시장 규모는 원화 기준 `조 원`으로 입력합니다.

- 미래 시장 규모 = 현재 시장 규모 × (1 + 성장률)^경과 연수
- 경쟁 가능 TAM = 미래 시장 규모 × 경쟁 가능 비율
- 출발 시가총액 = 사용자가 입력한 BTC 현재가 × 시작 연도 공급량 근사치
- 출발 침투율 = 출발 시가총액 ÷ 시작 연도 전체 경쟁 가능 TAM
- 연도별 침투율 = 출발 침투율 + (목표 침투율 − 출발 침투율) × 채택 진행률
- BTC 예상 시가총액 = 각 자산군의 경쟁 가능 TAM × 해당 연도 침투율의 합계
- BTC 예상 가격 = BTC 예상 시가총액 ÷ 해당 연도 BTC 공급량

공급량은 2024년 반감기 당시 19,687,500 BTC를 기준으로, 평균 10분 블록과 210,000블록마다 보상이 절반이 되는 구조를 적용한 연말 근사치입니다. 공급량은 2,100만 BTC를 넘지 않습니다. 분실 코인과 실제 블록 생성 속도의 차이는 반영하지 않습니다.

이전에는 목표 침투율을 시작 연도부터 100% 적용해 채택 과정이 없었고, 포트폴리오·Monte Carlo에서만 첫해 가격을 덮어써 비교 차트와 경로가 달랐습니다. 이제 모든 화면은 **현재가에서 시작하는 동일한 채택 경로**를 사용하며 첫해만 따로 덮어쓰지 않습니다. 목표 침투율·시장 규모·경쟁 비율을 바꿔도 시작 가격은 변하지 않습니다. BTC 현재가 자체를 수정하거나 새로 조회하면 출발점이 바뀝니다.

현재 시가총액을 각 자산군의 경쟁 가능 시장 규모에 비례 배분하므로 공통 출발 침투율을 사용합니다. 이 값은 현재가에 맞춘 보정값이며 관측한 자금 출처나 시장점유율이 아닙니다. 경쟁 가능 TAM이 0이거나 현재 BTC 시가총액보다 작으면 모형의 전제가 맞지 않으므로 안내합니다. 목표 침투율이 출발값보다 낮은 자산은 점진적으로 비중이 감소합니다. 자산군 간 중복과 실제 자금 이동은 별도로 추정하지 않습니다.

기본 채택 곡선은 시작 연도에 0, 목표 연도에 1이 되도록 정규화한 logistic S곡선입니다. `x=(연도-시작)/(목표-시작)`, `c=(가속 중심-시작)/(목표-시작)`, `L(x)=1/(1+exp(-강도×(x-c)))`, `진행률=(L(x)-L(0))/(L(1)-L(0))`입니다. 목표 이후 진행률은 1로 유지합니다. 선형 곡선은 `진행률=x`를 사용합니다. 가속 중심은 기울기가 가장 큰 시점이며 정규화 후 항상 50% 도달 연도인 것은 아닙니다. 강도는 1~20이며 기본 8입니다. 조회 종료 연도는 식에 사용하지 않으므로 조회 기간을 늘려도 기존 연도 경로가 바뀌지 않습니다.

신규 기본값은 목표 2045년·가속 중심 2035.5년입니다. 기존 저장값은 시장 규모·성장률·경쟁 비율·침투율을 유지하고, 침투율을 목표값으로 해석합니다. 이전 설정을 처음 읽을 때 저장된 종료 연도를 목표 연도로 사용하고(최소 시작 다음 해), 그 이후에는 목표 연도를 독립적으로 저장합니다. 새 저장 형식은 version 7입니다.

TAM 화면은 선택한 포트폴리오 모형과 관계없이 가격 경로, 채택 진행률, 자산군별 출발/현재/목표 침투율, 가치 기여와 연도별 표를 표시합니다. 선택적으로 목표 침투율을 즉시 적용한 참고선을 점선으로 비교할 수 있습니다. 이 참고선은 자산 계산에 사용하지 않습니다. 목표 이후에는 침투율이 유지되고 시장 성장과 공급량 변화가 가격에 계속 반영됩니다. 채택 진행률이 S자여도 가격 자체는 성장률과 공급량에 따라 다르게 움직일 수 있습니다.

기본 가정·시작 가격 1억 원 예시: 2026년 1억 → 2030년 약 1.184억 → 2035년 약 1.716억 → 2045년 약 3.148억 원. 같은 목표값을 처음부터 적용했던 기존 모델의 2026년 가격은 약 1.622억 원이었습니다. 모두 모형 설명용 숫자이며 시세나 전망치가 아닙니다. 목표 침투율이 모두 0이면 TAM 표에는 목표 가격 0을 표시하나, 가격으로 추가 매수 수량을 계산하는 포트폴리오와 Monte Carlo에는 양수 경로가 필요합니다.

확인: 목표 침투율을 바꿔도 시작 가격 유지, 목표 시점·가속 중심에 따른 중간 경로 변화, 조회 기간을 늘렸을 때 기존 경로 유지, 목표 이후 침투율 유지, 비교 차트·포트폴리오·Monte Carlo 경로 일치, 새로고침 후 가정 복원을 확인하세요. Monte Carlo는 가정 변경 후 실행 버튼으로 다시 계산해야 합니다.

## STEP 4 — Bitcoin Power Law

Power Law는 역사적 장기 가격궤도 기반 참고 모델입니다. TAM은 경제적 시장점유율 기반이며, 두 값을 평균내지 않습니다. 포트폴리오는 기존 CAGR 또는 TAM을 그대로 사용하고 Power Law는 비교 차트와 카드에만 표시합니다.

- USD 기준값 = 10^절편 × 경과 일수^β
- 지지/저항 = USD 기준값 × 각각의 배수
- KRW 비교값 = USD 값 × 사용자가 입력한 고정 USD/KRW 환산율

기준일은 Bitcoin genesis 날짜인 2009-01-03 00:00 UTC이며, 각 연도의 계산 날짜는 12월 31일 00:00 UTC입니다. `t`는 UTC 경과 일수이고 윤년을 반영합니다. 기본 지수 5.84509376과 절편 -17.01593313은 [Burger의 2019년 회귀식](https://hcburger.com/blog/powerlaw/)을 참고했습니다. 원문은 ‘2009년 이후 일수’로 기술하며 이 앱은 2009-01-03을 기준점으로 명시합니다. 현재 데이터에 새로 회귀한 계수는 아닙니다. 지지 0.5×·저항 2×·환산율 1,400 KRW/USD는 설명용 가정입니다. 배수는 통계적 신뢰구간이나 가격 한계를 보장하지 않습니다.

지수·절편·배수·고정 환산율을 수정하거나 preset으로 되돌릴 수 있습니다. 가정은 자동 저장됩니다. STEP 2/3 저장값은 보존하고 새 가정만 기본값으로 추가합니다. TAM 가정 입력은 CAGR 모드에서도 비교 차트를 위해 사용할 수 있습니다. 비교 차트의 네 선을 개별적으로 켜고 끌 수 있고, 점에 마우스를 올리면 해당 연도 값을 표시합니다.

확인: Power Law 계수 변경 시 카드와 차트 갱신, 네 선 토글, 포트폴리오 순자산 유지, 새로고침 후 계수 복원, preset 초기화와 모바일 배치를 확인하세요. Power Law 환산율은 참고 모델 비교에만 사용하며 환율 시뮬레이션은 아닙니다. 실제 시장이 과거 궤도에서 벗어날 수 있습니다.

## STEP 5 — 온체인 참고 지표

Realized Cap, Thermocap, Liveliness, Spot Price, 유통 공급량을 직접 입력합니다. 시가총액은 기본적으로 Spot × 유통 공급량을 사용하거나 직접 입력할 수 있습니다. 시가총액 입력 단위는 `십억 USD (Billion)`이며 가격은 `USD / BTC`, 공급량은 `BTC`, Liveliness는 `0~1`입니다. 기본값은 모두 설명용 예시입니다. 같은 시점·같은 통화의 데이터를 사용하세요. 온체인 모듈은 기존 BTC 현재가 자동 조회와 별도이며 API에 연결하지 않습니다.

- Classic MVRV = BTC Market Cap / Realized Cap
- Realized Price = Realized Cap / 유통 공급량
- Realized Price의 Spot 대비 차이 = (Realized Price / Spot − 1) × 100%
- Investor Cap = Realized Cap − Thermocap
- Active Supply = 유통 공급량 × Liveliness
- True Market Mean = Investor Cap / Active Supply
- AVIV = Spot / True Market Mean

이 계산은 [Glassnode의 Cointime / AVIV 정의](https://studio.glassnode.com/charts/9b030e1f-e9ea-4cfb-514e-8e1396133ca7?a=BTC)를 따릅니다. 공식 MVRV와 Cointime 지표는 항상 표시하고, 공급량 비교 방식은 별도로 선택합니다. 기본 비교 방식은 Cointime Weighted입니다. Classic은 전체 유통 공급량, 5/7/10년 이상 제외는 유통 공급량에서 해당 누적 미이동 공급량을 한 번 차감합니다. 누적 수량은 사용자가 입력하며 `5년 이상 ≥ 7년 이상 ≥ 10년 이상`이어야 합니다.

연령 제외는 실험용입니다. 오래 움직이지 않은 코인을 분실로 확정하지 않으며 Investor Cap은 유지한 채 공급량만 바꾸므로 연령별 취득원가 조정 모델이 아닙니다. 따라서 Cointime 이외의 비교 기준가/비율은 공식 True Market Mean/AVIV라고 표시하지 않습니다. Classic MVRV는 비교 방식에 영향을 받지 않습니다. Active Supply가 0이면 True Market Mean을 계산할 수 없으며, Investor Cap이 0이면 AVIV를 계산할 수 없습니다. 해당 값은 ‘계산 불가’로 표시합니다.

입력 변환은 `src/onchainInput.ts`, 계산 함수는 `src/onchain.ts`, 화면은 `src/OnchainPanel.tsx`로 분리했습니다. 이전 단계의 저장값을 유지하며 온체인 입력과 선택값도 저장합니다. 지표 카드의 ⓘ 버튼으로 설명을 열 수 있습니다.

직접 확인: Realized Cap·Liveliness 변경 후 카드 갱신, Market Cap 입력 방식 전환, Classic/Cointime/연령 제외 비교, ⓘ 설명 버튼, 새로고침 후 복원, Liveliness=0의 계산 불가 표시, 온체인 값을 바꿔도 포트폴리오 결과 유지 여부를 확인하세요.

## STEP 6 — 연도별 모델 비교

`Bitcoin Valuation Chart`와 표에서 CAGR BTC 가격, TAM 가격, Power Law Support/Fair/Resistance, True Market Mean 또는 선택한 Active Cost Basis, BTC 공급량을 1년 단위로 비교합니다. 기본 범위는 2026~2045입니다. 모든 모델을 함께 비교하는 범위는 공급량 근사 함수에 맞춰 2024~2200입니다. 가격 단위는 KRW/BTC이고 공급량은 BTC입니다.

모델별 표시 토글과 선형/로그 가격 축을 제공합니다. 0 이하 값은 로그 차트에서 생략하고 표에서는 유지합니다. 차트·표의 연도나 상세 연도 목록을 선택하면 해당 연도의 TAM, Power Law, MVRV/AVIV, 선택 모델 시가총액 카드가 바뀝니다. 2030/2035/2040/2045 빠른 선택 버튼은 입력 범위 밖에서는 비활성화됩니다. 차트 토글·축·선택 연도는 화면 상태이며 새로고침 시 기본 상태로 돌아갑니다.

연도별 온체인 비교는 새로운 예측 모델 없이 현재 입력을 유지하는 가정을 사용합니다. Realized Cap·Thermocap·Liveliness와 미이동 공급 **비율**을 고정하고 공급량만 각 연도의 발행 근사치로 변경합니다. 가격/시가총액은 선택한 CAGR 또는 TAM을 사용합니다. 연도별 MVRV = 모델 시가총액(KRW) ÷ 고정 환산율 ÷ Realized Cap(USD), AVIV = 모델 가격(KRW) ÷ 고정 환산율 ÷ 해당 연도 True Market Mean(USD)입니다. 온체인 모듈에 직접 입력한 시가총액·Spot 대신 연도별 모델값을 사용하므로 STEP 5의 현재 스냅샷과 결과가 다를 수 있습니다. 온체인 참고선은 미래 온체인 데이터의 예측값이 아닙니다.

고정 환산율은 Power Law 설정의 USD/KRW를 공유하며, CAGR·TAM 원화 가격 자체에는 환산율을 곱하지 않습니다. 기존 Power Law 비교 차트는 통합 차트로 모았습니다. 각 모델이 계산 불가이면 해당 값은 —로 표시하고 유효한 모델은 유지합니다. 포트폴리오 계산은 그대로입니다.

확인: 20개 연도 행, 모델별 토글, 로그 축, 2030/2035/2040/2045 카드 전환, 사용자 연도 범위 변경, 온체인 공급량 비교 방식에 따른 참고선 변경, 입력 수정 시 즉시 결과 갱신과 모바일 가로 스크롤을 확인하세요.

## STEP 7 — 기본 Monte Carlo

`여러 경로로 보는 미래 순자산`에서 기본 10,000회, 선택 1,000 / 10,000 / 100,000회를 실행합니다. Web Worker에서 계산하므로 화면과 분리되며 진행률과 취소 버튼을 제공합니다. 자동 실행하지 않으므로 입력을 수정한 후 실행 버튼을 누르세요. 같은 가정과 seed는 같은 결과를 재현합니다.

- 초기 자산, 기간, 월 납입액, 부채 연이율은 위 포트폴리오 입력을 사용합니다. 주식 전체를 QQQ로 취급합니다. BTC·QQQ 수익률과 물가는 Monte Carlo 전용 입력값을 사용합니다.
- BTC는 USD 기대수익률 또는 TAM 중심 가격을 선택합니다. TAM은 현재가에서 시작해 설정한 채택 곡선에 따라 목표 침투율로 이동하는 경로를 사용합니다. TAM 원화 가격을 입력 평균 환율로 USD로 변환한 중심 경로를 사용하며, 실행 가정에 채택 설정을 기록합니다.
- 기대수익률은 연간 단순수익률의 **산술 평균**, 변동성은 **로그수익률 표준편차(%)**입니다. 연간 성장배율은 `(1 + 평균수익률) × exp(-σ²/2 + σZ)`이고 Z는 독립 표준정규 난수입니다. σ는 입력 변동성 / 100입니다. 따라서 기대수익률은 중앙값이나 장기 CAGR과 다릅니다.
- 선택적 BTC 상·하한은 USD 연간 수익률을 잘라 적용합니다. 원화 수익률에는 환율 변동이 추가됩니다. 제한을 적용하면 실제 평균이 입력 평균 또는 TAM 중심과 달라질 수 있습니다.
- 물가배율도 같은 로그정규 식으로 생성하고 누적합니다. 실질 순자산은 **각 경로의 명목 순자산 / 각 경로의 누적 물가**를 먼저 계산한 뒤 분위수를 구합니다.
- USD/KRW는 매년 입력 평균 주변의 로그정규 **수준**을 독립 추출합니다. 전년 대비 환율 수익률을 누적하는 모형이 아닙니다. 시작 환율은 입력 평균입니다. BTC와 QQQ의 USD 평가액에 같은 환율을 적용하며 현금·부채·납입액은 KRW로 유지합니다. 자산 수익률 충격은 서로 독립이지만 원화 평가액은 동일 환율의 영향을 받습니다.
- 연말에 월 납입액 × 12를 외부 소득으로 추가 투자하며, 현금은 고정이고 부채는 복리로 증가합니다. 세금·수수료와 배당의 별도 현금흐름은 제외합니다.

명목/실질 KRW를 전환해 연도별 P10·P25·P50·P75·P90과 평균을 확인합니다. Fan chart는 P10–P90과 P25–P75 음영, 굵은 P50 중앙값을 표시하며 평균은 표에 참고로만 표시합니다. 분위수는 정렬한 표본의 `(N-1)q` 위치를 선형 보간합니다. 각 연도별 분포이며 중앙값 선 자체가 하나의 투자 경로는 아닙니다. 음수 순자산도 유지합니다.

실행 완료 결과에는 사용한 가정을 남깁니다. 입력값이 바뀌면 이전 가정의 결과임을 알립니다. 설정만 자동 저장하며 계산 결과는 새로고침 후 다시 실행해야 합니다. 이전 STEP 1~6 설정을 유지하고 Monte Carlo 기본값을 추가합니다. `src/monteCarlo.ts`에 계산, `src/monteCarlo.worker.ts`에 별도 작업, `src/MonteCarloPanel.tsx`에 화면을 분리했습니다.

메모리 보호를 위해 연도 수 × 경로 수는 5,000,000 이하로 제한합니다. 기본 20년 × 100,000회는 지원합니다. 계산 범위를 벗어나는 극단적 가정은 오류를 표시하고 전체 실행을 중단하며 경로를 임의로 버리지 않습니다. 기본값은 추정된 시장 수치가 아닌 예시입니다. STEP 9의 목표 달성 확률 등은 아직 구현하지 않았습니다.

확인: 10,000회 실행, 명목/실질 전환, 표의 5개 분위수와 중앙값, seed 재실행, 입력 변경 안내, 설정 저장·복원, 100,000회 실행과 취소, TAM 중심 선택을 확인하세요. 모든 변동성을 0으로 하고 수익률·물가를 기존 포트폴리오와 맞추면 결정론적 계산과 일치해야 합니다.

## STEP 8 — Fat Tail · Market Regime · Jump

Monte Carlo의 `시장 움직임 가정`에서 세 기능을 설정합니다. 기본값은 Normal / 국면 전환 OFF / Jump OFF이며 기존 STEP 7과 같은 난수 순서와 계산을 유지합니다. 이전 저장값은 유지하고 새 가정만 기본값으로 추가합니다. 실행 후 입력을 변경하면 이전 결과임을 표시하며, 완료 시 사용한 분포·국면 가정·전이행렬·Jump 값을 결과에 남깁니다.

### Normal / Student-t

- Normal은 STEP 7의 로그정규 가격 모형입니다. 변동성은 **로그수익률 표준편차**입니다.
- Student-t는 **단순수익률**에 적용합니다. 자유도 기본 5, 허용 범위는 `2 < df ≤ 200`이며 소수 자유도도 지원합니다. 표준정규 충격 쌍에 같은 카이제곱 스케일 `sqrt((df-2)/χ²(df))`을 곱해 각 충격의 분산을 1로 맞춥니다. 카이제곱은 Gamma(df/2, 2)를 Marsaglia–Tsang 방식으로 추출합니다. 분포 정의 참고: [SciPy Student-t](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.t.html), [SciPy Chi-square](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.chi2.html).
- Student-t 연간 성장배율은 `max(0.001, 중심배율 + 변동성 × T)`입니다. 변동성은 **절단 전 단순수익률 표준편차**이고 입력 기대수익률은 절단 전 평균입니다. 음수 가격과 연말 매수의 0 나눗셈을 막기 위해 기본 수익률의 손실을 −99.9%에서 제한합니다. 절단으로 실제 평균과 변동성이 달라집니다. Student-t를 지수화한 가격 모형은 사용하지 않습니다.
- 두 선택은 수익률을 적용하는 방식과 변동성 정의가 다릅니다. 같은 수치로 전환했을 때 꼬리 모양만 달라지는 비교는 아닙니다. 물가·환율은 두 선택 모두 기존 로그정규 모형입니다.

### 시장 국면과 상관관계

Risk-On / Normal / Crisis 각각의 BTC·QQQ 수익률 중심, 변동성, BTC–QQQ 충격 상관계수(-1~1)를 설정합니다. ON이면 국면별 가정이 기본 BTC·QQQ 수익률·변동성 입력을 대체합니다. 첫 투자 연도(기본 2027년)는 선택한 초기 국면(기본 Normal)을 사용합니다. 이후 각 연도는 직전 국면 행의 Markov 확률로 한 번 전이합니다. 시작 연도(2026년)는 현재 자산이므로 수익률과 전이를 적용하지 않습니다.

전이행렬은 행이 현재 국면, 열이 다음 국면이며 각 값 0~100%, 각 행 합계 100%여야 합니다. 국면은 각 경로에서 따로 추출하고 해당 경로의 BTC와 QQQ가 공유합니다. 결과에서 연도별 실제 국면 비율을 확인할 수 있습니다.

충격 쌍은 `Z₁`, `ρZ₁ + sqrt(1-ρ²)Z₂`로 만듭니다. Student-t는 여기에 공통 카이제곱 스케일을 적용합니다. 입력 상관계수는 변환 전 충격의 Pearson 상관이며 로그정규 변환, 손실 하한, Jump, 환율 적용 후 실제 수익률 상관과는 다릅니다. 국면 OFF에서는 상관계수 0을 사용합니다. Student-t에서는 상관계수 0이어도 공통 스케일 때문에 극단적 충격 크기가 독립은 아닙니다. 물가·환율 충격은 자산 충격과 독립입니다.

TAM과 국면을 함께 쓰면 Normal 국면의 BTC 중심은 TAM 연간 가격배율입니다. 다른 국면에서는 `TAM 배율 × (1 + 해당 국면 BTC 수익률) / (1 + Normal 국면 BTC 수익률)`로 조정합니다. Normal의 입력 수익률은 이 상대 조정의 기준입니다. 따라서 모든 국면의 BTC 수익률이 같고 변동성이 0이면 TAM 경로와 일치합니다. 국면 전환 시 장기 평균이 TAM 가격에 고정되지는 않습니다.

### BTC Jump

기본 OFF이며 예시는 급락 확률 연 3% / 하락 폭 30%, 급등 확률 연 2% / 상승 폭 50%입니다. 두 확률 합계는 100% 이하이고 급락 폭은 0 이상 100% 미만, 급등 폭은 0 이상입니다. 모두 양수 크기로 입력합니다. 매년 `급락 / 급등 / 없음` 중 하나를 추출하는 연간 이산 이벤트 모형이며 국면·자산 충격과 독립입니다.

적용 순서는 `국면 선택 → 자산 수익률 추출(Student-t 손실 하한 포함) → BTC Jump 곱셈 → 사용자가 선택한 BTC 수익률 상·하한 → 환율 평가·연말 납입`입니다. 예를 들어 수익률 +10% 후 30% 급락이면 `1.1 × 0.7 - 1 = -23%`입니다. Jump는 QQQ에 직접 적용하지 않습니다. Student-t 하한 이후 Jump가 적용되므로 최종 손실은 −99.9%보다 클 수 있습니다. 사용자 상·하한을 적용하면 급락·급등 효과가 제한될 수 있습니다. Jump는 평균을 재보정하지 않습니다.

결과에 전체 경로·연도의 급락·급등 발생 횟수와 BTC·QQQ Student-t 손실 하한 적용 횟수를 표시합니다. 발생 횟수는 사용자 최종 상·하한 적용 전의 이벤트 횟수입니다. 순자산 분위수와 fan chart, 명목/실질 전환, Worker 진행률·취소는 그대로 사용합니다. 모든 기본 국면·확률은 설명용 예시이며 시장에서 추정한 값이 아닙니다.

검증: Student-t의 평균·분산·꼬리 표본과 상관계수, 소수 자유도, 전이확률 경계와 행 방향, 초기 국면 적용 순서, TAM 상대 조정, Jump 100% 경계와 상·하한 순서, 하한 횟수, seed 재현성, 기존 설정 이전을 자동 테스트합니다. 직접 확인할 항목은 Student-t 선택과 df 변경, 국면 ON 후 전이확률 수정(잘못된 행 합계 안내), Jump ON/OFF 후 재실행, 연도별 국면 비율, 새로고침 후 복원입니다.

## BTC 현재가 자동 조회

자동 조회가 켜져 있으면 접속 시 업비트 공개 API의 KRW-BTC 최근 체결 가격을 BTC 가격 입력칸에 반영합니다. API 키나 백엔드는 필요하지 않습니다. 출처와 체결 시각(한국 시간)을 표시하며, 버튼으로 다시 조회할 수 있습니다. 주기적으로 자동 갱신하지는 않습니다. 직접 가격을 입력하면 자동 조회가 꺼지고, 가격과 선택이 함께 저장됩니다.

10초 안에 응답하지 않거나 연결/응답 오류가 있으면 기존 입력값을 유지하고 안내를 표시합니다. 인터넷 연결과 API 서비스 상태에 따라 조회가 실패할 수 있습니다. 시세는 업비트 원화 시장 가격이며 전 세계 통합 가격이 아닙니다.

확인: 접속 시 BTC 가격 변경, 새로고침 버튼, 직접 입력 안내, 인터넷 연결 해제 후 조회 실패 시 기존 가격 유지를 확인하세요.
