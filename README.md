# 비트코인 시뮬레이터

BTC 보유 수량, 현재 원화 가격, 월 투자금으로 미래 BTC 평가액을 계산하는 로컬 웹앱입니다. CAGR·Monte Carlo·Power Law를 한 그래프에서 전환합니다.

## 실행

`시뮬레이터 실행.cmd`를 더블클릭하세요. 기본 주소는 `http://127.0.0.1:5175/`입니다. 이미 켜진 시뮬레이터는 재사용하며 다른 Node 프로그램이 기본 포트를 쓰면 5176~5194 중 빈 포트에서 실행합니다. 다른 Node 프로세스를 종료하지 않습니다.

```powershell
npm.cmd run dev -- --port 5175 --strictPort
npm.cmd run build
npm.cmd test
```

Node.js 22.12 이상과 설치된 의존성이 필요합니다. 처음 설치할 때는 `npm.cmd install`을 실행하세요.

## 입력과 결과

현재 BTC 수량과 월 BTC 투자금의 기본값은 0입니다. 처음 접속하거나 기본값으로 초기화할 때 적용하며, 기존에 저장한 사용자 입력은 보존합니다.

입력: BTC 수량, 현재 BTC 가격, 월 BTC 투자금, 목표 연도, BTC 수익률 또는 Power Law 베타. Monte Carlo에서는 BTC 변동성도 입력합니다. 시작 연도와 자동 시세 조회는 접힌 설정에 있습니다.

결과: 현재 BTC 평가액과 목표 연도의 BTC 평가액. CAGR·Power Law 상세 표에는 BTC 가격·수량·평가액을 표시하며 Monte Carlo에는 평가액 분위수와 평균을 표시합니다. 화면 맨 위 우측의 원화·달러 토글로 입력·요약·그래프·툴팁·상세 표를 함께 전환합니다. BTC 수량과 시뮬레이션은 원화 기준으로 유지하고 표시 금액만 현재 환율로 환산합니다. 통화 선택은 브라우저에 저장됩니다.

각 연도는 1월 1일(연초), UTC 기준의 자산 스냅샷입니다. 시작 연도에는 투자하지 않습니다. 이후 월 투자금 × 12를 다음 연도 스냅샷 가격으로 한 번에 매수하는 연 단위 근사입니다. 투자금은 새로 납입하는 금액이며 세금·수수료는 반영하지 않습니다.

## CAGR

BTC 가격 = 현재 가격 × (1 + 연 복리 성장률)^경과 연수.
BTC 수량 = 전년도 수량 + 연간 투자금 / 해당 연도 BTC 가격.
BTC 평가액 = BTC 수량 × BTC 가격.

## Power Law

`P(t) = P0 × (t / t0)^β`

P0는 현재 원화 가격입니다. t0와 t는 Genesis(2009-01-03)부터 시작 연도와 미래 연도 1월 1일까지의 경과일수입니다. 시작 연도 범위는 2010~2200년입니다. 연도만 입력하므로 현재 가격을 시작 연도 스냅샷의 가격으로 간주합니다.

`P = A × t^β`에서 `A = P0 / t0^β`로 기준점을 맞춥니다. 베타를 바꿔도 시작 가격과 시작 평가액은 그대로이며 이후 성장 곡선만 바뀝니다. 베타 0은 가격이 일정합니다. 기본 5.845는 사용자가 조정하는 성장 가정이며 검증된 예측값을 뜻하지 않습니다. 매수와 평가에는 같은 Power Law 가격을 사용합니다.

## Monte Carlo

항상 100,000개 BTC 원화 가격 경로를 계산합니다. 기본적으로 상승장·하락장 두 국면의 수익률 중심과 변동성을 사용합니다. 수익률 중심은 연간 단순수익률의 산술평균 가정이며 CAGR의 연 복리 성장률과는 의미가 다릅니다. 국면 사용을 끄면 단일 기대수익률·변동성을 직접 입력할 수 있습니다.

- 로그정규 모형: 성장배율 = `(1+평균수익률) × exp(-σ²/2+σZ)`. 변동성은 로그수익률 표준편차입니다.
- Student-t: 분산 1로 표준화한 단순수익률 충격을 사용하며 기본 손실은 −99.9%에서 제한합니다. 자유도는 2 초과 200 이하입니다.
- BTC 시장 국면: 상승장·하락장 두 가지. 기본 사용. 첫 투자 연도는 선택한 초기 국면을 적용하며 다음 해부터 Markov 전이합니다. 국면별 값은 CAGR 입력과 독립적입니다.
- 자료 기반 Jump: 급락·급등 횟수를 각각 포아송 분포로 추출하고, 관측된 일별 변동 폭을 재표본합니다. 같은 해에 양쪽 사건이 여러 번 발생할 수 있습니다. 선택적 수익률 상·하한은 마지막에 적용합니다.
- Student-t 손실 하한·국면·Jump·수익률 제한으로 실제 평균은 입력 가정과 달라질 수 있습니다. 모든 기본값은 설명용 가정입니다.

결과는 연도별 P20·P30·P40·P50·P60·P70·P80와 평균입니다. 범위는 해당 모델에서 추출한 각 연도의 평가액 분포이며 실제 결과의 보장 범위가 아닙니다. seed로 같은 결과를 재현할 수 있고 실행·취소·진행률·이전 결과 표시를 제공합니다. 연도 수 × 경로 수는 5,000,000 이하로 제한합니다.

## 저장과 현재가

localStorage 저장 형식은 version 15입니다. 이전 version 1~13 설정에서 BTC 수량·가격·월 투자금·기간·수익률·베타·자동 시세 조회와 BTC Monte Carlo 가정을 보존합니다. 이전의 주식·현금·부채·물가·환율·자산 간 상관관계는 계산과 저장에서 제거합니다. Monte Carlo 결과는 저장하지 않으며 입력이 바뀌면 다시 실행해야 합니다.

자동 조회는 업비트 공개 API의 KRW-BTC 체결 가격을 사용합니다. 직접 가격을 입력하면 자동 조회가 꺼집니다. 조회 실패 시 기존 가격을 유지하며 API 키는 필요 없습니다.

그래프는 마우스 호버, 클릭·터치 고정, Tab·Enter·Space·Esc 조작을 지원합니다. 툴팁은 그래프 축소와 독립적으로 글자 크기를 유지합니다.

## 변동성과 현재 환율

기본 국면 값은 사용자 지정 기간의 BTC 달러 일별 가격으로 추정한 로그정규 모형의 연간 산술평균 수익률 중심과 연 로그수익률 변동성입니다.

| 국면 | 자료 기간 | 수익률 중심 | 변동성 |
| --- | --- | --- | --- |
| 상승장 | 2022-11-30 가격 기준~2025-10-31 | +109.57% | 45.93% |
| 하락장 | 2021-11-01~2022-11-30 | −61.67% | 66.12% |

일별 로그수익률 평균 × 365를 μ, 표본 표준편차 × √365를 σ로 두고, 연간 산술평균 수익률은 exp(μ+σ²/2)−1로 환산했습니다. 2022년 11월 말 가격을 공통 전환점으로 사용합니다. 하락장 수익률은 2021-11-01~2022-11-30의 395개, 상승장 수익률은 2022-12-01~2025-10-31의 1,066개입니다. 상승장 시작 기준 가격은 2022-11-30 가격이며 겹치는 11월 수익률은 하락장에만 포함합니다. 이 값은 지정된 과거 구간의 추정치이며 미래 성과나 원화 변동성을 검증한 값은 아닙니다. Student-t 분포를 선택하면 수익률과 변동성 정의가 바뀝니다.

전이확률은 평균 상승장 약 3년·하락장 1년이라는 기간 가정입니다. 상승장→상승장 66.67%, 상승장→하락장 33.33%, 하락장→상승장 100%, 하락장→하락장 0%입니다. 자료에서 추정한 확률이 아니며 매 4년마다 정확히 반복되는 고정 주기가 아닙니다. 첫 투자 연도 기본 국면은 상승장이고 사용자가 변경할 수 있습니다.

version 1~12의 저장된 시장 설정은 새 두 국면 기본값으로 이전하며 BTC 보유량·현재 가격·투자금·기간·시세 조회·베타와 난수 seed 등 기본 실행 설정은 유지합니다. version 13 이후에 사용자가 수정한 국면 값은 보존합니다. 국면을 끄는 단일 모형의 기본 변동성은 기존 49%를 유지합니다.

USD/KRW는 Frankfurter v2 공개 API의 최신 고시 환율을 조회합니다. 접속·통화 전환·화면 복귀 시와 화면이 활성화된 동안 5분마다 자동 조회하며 기준일을 토글에 표시합니다. API 환율 자체는 일 단위로 갱신되며 장중 실시간 호가가 아닙니다. 주말·휴일에는 최신 제공 기준일의 환율을 사용합니다. 조회 실패 시 마지막 성공 환율과 실패 상태를 표시하며, 아직 환율이 없으면 임의 환율을 사용하지 않고 달러 금액과 금액 입력을 대기 상태로 표시합니다. 환율이 바뀌어도 기존 원화 투자금·BTC 수량·계산 결과는 바뀌지 않습니다. 미래 금액도 현재 조회 환율로 환산하며 미래 환율을 예측하지 않습니다.

## 자료 기반 복수 Jump

일별 달러 단순수익률이 −5% 이하인 날을 급락, +5% 이상인 날을 급등으로 정의합니다. 이는 임계값에 의한 분류이며 모든 해당 변동이 일반 변동과 구분되는 실제 잠재 Jump라는 뜻은 아닙니다. 상승장·하락장에는 각각 해당 자료 기간을 사용하고, 국면을 끄면 2022-05-24~2026-05-23의 최근 4년 전체를 사용합니다. 원본 가격은 수정하지 않고 사건의 로그 변동 폭을 계산에 필요한 자료로 보관합니다.

급락·급등 횟수는 독립 포아송 분포이며 연 발생률은 관측 사건 수 / 관측 일수 × 365입니다. 사건 폭은 해당 구간의 실제 급락·급등 로그 변동에서 복원 추출합니다. 기본 빈도 배율은 1입니다. 새 구간에서 상승장 연평균 급락 7.19회·급등 11.64회, 하락장에서는 28.65회·13.86회입니다. 사건의 군집이나 시간 의존성은 모델링하지 않습니다.

일반 변동과 Jump를 합친 연 로그수익률 평균·분산을 기존 총 목표값에 맞춥니다. Jump 로그 평균은 λ × E[J], 분산은 λ × E[J²]이며, 일반 변동에서 이 두 성분을 차감합니다. 이에 따라 변동성을 두 번 더하지 않습니다. 총 로그 평균·분산이 같아도 분포 모양과 산술평균·중앙값은 Jump를 끈 모형과 조금 달라질 수 있습니다. Jump 분산이 총 목표 분산보다 커지면 임의로 보정하지 않고 입력 오류를 표시합니다.

Jump는 기본적으로 사용하며 로그정규 모형에서만 적용합니다. Student-t 선택 시 Jump는 꺼집니다. 연간 사건은 한 해의 가격 배율에 합산하고, BTC 적립은 기존 연 단위 근사를 유지합니다. 빈도 배율 0은 Jump를 끈 계산과 일치합니다. 이전 단일 Jump 확률·고정 폭 입력은 제거하고, 기존 설정을 새 자료 기반 방식으로 이전합니다. 현재 형식에서 사용자가 끈 Jump 또는 조정한 빈도 배율은 보존합니다.

이전 설정의 변동성이 Jump 분산보다 낮으면 해당 사용자 값을 보존하고 Jump를 꺼서 이전합니다. 이후 총 변동성을 높이거나 빈도 배율을 낮춰 활성화할 수 있습니다.

version 15에서 과거 기본 수익률·변동성 값만 새 자료 기간의 추정치로 갱신합니다. 사용자가 변경한 값, 전이확률, 초기 국면, BTC 입력, 시세 조회 설정은 보존합니다. 새 Jump 자료와 기존 사용자 변동성이 맞지 않으면 값을 보존하고 Jump를 꺼서 이전합니다.

몬테카를로 그래프는 P20·P30·P40·P50·P60·P70·P80 일곱 선을 표시합니다. P50은 중앙값입니다. 음영은 P20~P80(60% 범위)과 P30~P60(30% 범위)이며 중앙값 기준 대칭 범위는 아닙니다. 평균은 상세 표의 참고 값입니다.
